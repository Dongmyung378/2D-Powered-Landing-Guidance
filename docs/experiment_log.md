# 프로젝트 실험 기록

이 문서는 일차별 구현 내용, 검증 방법, 실제 결과와 남은 한계를 한곳에 기록합니다. 생성된 그림과 에피소드 파일은 Git에 넣지 않고 필요할 때 다시 만들며, 재현에 필요한 명령과 seed는 이 문서에 남깁니다.

## 1주차 시뮬레이터와 검증 기반

### 1일차 프로젝트 규격과 환경

Python 3.12.7을 기준 환경으로 정하고 상태와 제어 벡터의 순서를 고정했습니다. +x는 오른쪽, +z는 위쪽이며 theta의 양의 방향은 기수가 +x로 기울어지는 방향입니다. 내부 각도 단위는 rad이고 사람이 입력하는 설정값에만 deg 접미사를 사용합니다.

검증 내용:

- 패키지 import와 버전 확인
- 상태 7개와 제어 2개의 순서 및 단위 확인
- YAML 설정 유효성 확인

### 2일차 병진 동역학

수평과 수직 위치 및 속도, 중력과 추력 벡터를 구현했습니다. Euler와 RK4 적분기를 분리하고 자유낙하와 가변 질량 수직 상승을 해석값과 비교했습니다.

검증 내용:

- 무추력 자유낙하 위치와 속도
- 수직 추력에서 수평 운동이 생기지 않는지 확인
- 수치 적분 결과와 해석해 비교

### 3일차 회전과 짐벌

theta, omega, 관성모멘트, 엔진 레버암과 짐벌 토크를 추가했습니다. 스로틀과 짐벌 명령은 물리 모델에 들어가기 전에 허용 범위로 제한됩니다.

검증 내용:

- 양의 자세각에서 수평 추력이 +x를 향하는지 확인
- 양의 짐벌에서 음의 회전 토크가 생기는지 확인
- 짐벌 제한과 내부 rad 단위 확인

### 4일차 연료 소모와 추력 차단

비추력과 표준중력으로 질량 유량을 계산하고, 적분 구간 중간에 연료가 소진되면 해당 시각에서 구간을 나누도록 구현했습니다. 건조 질량에 도달한 이후에는 추력, 토크와 질량 유량이 0이 됩니다.

검증 내용:

- 일정 추력의 연료 소모량과 이론값 비교
- 건조 질량 아래로 내려가지 않는지 확인
- 연료 소진 이후 탄도 운동 확인

### 5일차 Gymnasium 환경

reset, step, 관측 공간과 행동 공간을 구현했습니다. 성공, 강한 착륙, 충돌, 연료 고갈, 시간 초과를 구분하고 지면 접촉, 연료 고갈, 시간 제한이 같은 스텝에 있을 때 가장 먼저 발생한 사건을 선택합니다.

검증 내용:

- 동일 seed의 초기조건과 궤적 재현
- 지면 최초 접촉 시각 탐색
- 종료 우선순위와 terminated 또는 truncated 구분
- 에피소드 기록의 복사 안전성과 JSON 직렬화

### 6일차 기록 재생과 시각화

에피소드를 JSON 또는 압축 NPZ로 저장하고, 물리를 다시 계산하지 않고 기록된 상태를 재생하도록 구현했습니다. 상태와 제어 시계열 PNG, 로켓 자세와 추력 벡터를 포함하는 GIF 또는 MP4를 만들 수 있습니다.

검증 내용:

- JSON과 NPZ 왕복 저장
- 상태 수와 행동 수의 시간축 정렬
- PNG와 GIF 파일 생성
- 좌표 순서가 다른 잘못된 기록 거부

### 7일차 1주차 통합 검증

설정 경계 검사를 보강하고 scripts/verify_week1.py를 추가했습니다. 검증 도구는 물리 부호와 단위를 확인하고 5가지 종료 상황을 각각 재현한 뒤, 기본 초기조건 범위에서 무작위 행동 에피소드 100회를 끝까지 실행합니다.

실행 환경:

- 실행일: 2026-09-07
- 운영체제: Windows
- Python: 3.12.7
- 무작위 검증 seed: 20260907
- 무작위 에피소드: 100회

실행 명령:

~~~powershell
python -m pytest -p no:cacheprovider
python scripts/verify_week1.py --episodes 100 --seed 20260907
python -m ruff check --no-cache .
python -m ruff format --check --no-cache .
~~~

실제 결과:

| pytest | 103개 통과 |
| Gymnasium 권고 경고 | 2개 |

| 독립 종료 상황 | 5종 모두 통과 |
| 무작위 에피소드 | 100회 완료 |
| 총 시뮬레이션 스텝 | 25,245 |

| 시간 역행 및 기록 불일치 | 없음 |

무작위 명령은 현재 상태를 보고 판단하지 않으므로 100회 모두 충돌한 결과가 정상입니다. 이 결과는 자동착륙 성공률이 아니라 제어기가 없는 기준선이며, 다양한 입력에서도 시뮬레이터가 수치 오류 없이 종료되는지를 보여줍니다.

이번 점검에서 설정 단계의 오류를 더 일찍 발견하도록 다음 검사를 추가했습니다.

- 지면 높이와 명목 초기 상태의 NaN 및 Inf 거부
- 숫자 항목에 들어온 boolean 값 거부
- 초기 고도가 지면보다 낮은 설정 거부
- Euler와 RK4 이외의 적분기 이름 거부
- theta 영점 좌표계 규약 확인
- 90 deg를 초과하는 짐벌 한계 거부
- 착륙 판정 필수 설정 확인

## 1주차 결론

로드맵의 1주차 완료 조건을 충족했습니다. 전체 핵심 테스트가 통과했고, 100회 무작위 에피소드에서 NaN과 수치 경계 침범이 없었으며, 성공, 강한 착륙, 충돌, 연료 고갈과 시간 초과를 독립적으로 확인했습니다.

현재 성공 판정은 시뮬레이터의 사건 분류가 작동한다는 뜻입니다. 높은 고도와 다양한 속도에서 자동으로 안전하게 착륙하는 기능은 아직 없으며, 8일차 suicide-burn 계산부터 실제 제어기 구현을 시작합니다.

## 현재 알려진 한계

- 공기저항과 바람은 아직 운동방정식에 적용하지 않음
- 센서 오차, 추력 오차와 엔진 지연을 적용하지 않음
- 착륙 다리와 구조 충격을 모델링하지 않음
- 관성모멘트와 엔진 레버암이 질량 변화와 무관하게 고정됨
- 무작위 행동 검증은 안정성 검사이며 제어 성능 평가가 아님

2주차부터는 같은 초기조건 집합을 사용해 제어기의 성공률, 접지 속도, 위치 오차와 사용 연료를 비교합니다.
